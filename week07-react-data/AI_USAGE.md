# Mākslīgā intelekta izmantošana

**Vārds, uzvārds:** Rolands Timonovs
**Izmantotais(-ie) MI rīks(-i):** Codex

## Kam es izmantoju mākslīgo intelektu?

Codex palīdzēja pārcelt datu ielādi uz React un saprast pieprasījumu atcelšanu.

## Kuru kodu vai konfigurāciju būtiskā apjomā ģenerēja mākslīgais intelekts?

Ar MI palīdzību sagatavots useFetch un izmaiņas App, WeatherCard un Layout.

## Kuru kodu vai konfigurāciju es uzrakstīju pats/pati vai būtiski pārveidoju?

Turpināta 6. nedēļas lietotne ar tām pašām lapām.

## Viens MI ieteikums, kuru es noraidīju vai izmainīju

Konkrēts noraidīts ieteikums nav pierakstīts. useFetch saņem funkcijas no api.ts. Tas palīdz izvairīties no atkārtotas ielādes katrā zīmēšanā.

## Viena lieta, kuru es pārbaudīju pats/pati, nevis vienkārši uzticējos MI atbildei

Codex salīdzināja dev un preview režīmu un pārbaudīja pāreju prom ielādes laikā. Mana pārbaude vēl jāveic.
