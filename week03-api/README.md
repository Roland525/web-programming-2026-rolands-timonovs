# CampusFlow — 3. nedēļa

Dati no API. Projekti un termiņi nāk no JSON failiem. Api.ts saņem datus, guards.ts tos pārbauda, main.ts vada ielādi, bet render.ts rāda lapu.

## Palaišana

```bash
npm ci
npm run dev
```

## Pārbaude

```bash
npm run build
```

Pārbaudīta ielāde, kļūdu un tukšie stāvokļi, filtri un mobilā izvēlne. Pārbaudīta forma un saglabāšana pēc pārlādes. Pārlūka automatizētajās pārbaudēs laikapstākļu atbilde bija testa dati. Atsevišķi pārbaudīts arī dzīvais Open-Meteo pieprasījums 7. nedēļas lapā.

## Papildu uzdevums

Pieprasījumam ir 8 sekunžu noildze.

REFLECTION.md ir mācību melnraksts. Uzdevumā gala refleksija jāaizpilda individuāli.
