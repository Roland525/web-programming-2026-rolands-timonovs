# Mākslīgā intelekta izmantošana

**Vārds, uzvārds:** Rolands Timonovs
**Izmantotais(-ie) MI rīks(-i):** Codex

## Kam es izmantoju mākslīgo intelektu?

Codex palīdzēja izveidot datu ielādi un pārbaudīt, kas notiek, ja API atbilde ir nepareiza.

## Kuru kodu vai konfigurāciju būtiskā apjomā ģenerēja mākslīgais intelekts?

Ar MI palīdzību sagatavoti api.ts, guards.ts un ielādes un kļūdu paziņojumi.

## Kuru kodu vai konfigurāciju es uzrakstīju pats/pati vai būtiski pārveidoju?

Par pamatu izmantota iepriekšējās nedēļas lapa.

## Viens MI ieteikums, kuru es noraidīju vai izmainīju

Konkrēts noraidīts ieteikums nav pierakstīts. Izvēlēts risinājums ar fetch un atsevišķu api.ts failu, kā prasīts uzdevumā.

## Viena lieta, kuru es pārbaudīju pats/pati, nevis vienkārši uzticējos MI atbildei

Codex pārlūkā pārbaudīja bloķētu pieprasījumu, nepareizu JSON un pogu Try again. Mana pārbaude vēl jāveic.
