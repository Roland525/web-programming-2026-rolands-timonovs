# CampusFlow — 6. nedēļa

Atsevišķas lapas. App nosaka maršrutus. Layout rāda kopīgu galveni un kājeni. Pages mapē ir Dashboard, Projects, Deadlines, projekta detaļas un 404 lapa.

## Palaišana

```bash
npm ci
npm run dev
```

## Pārbaude

```bash
npm run build
npm run lint
```

Pārbaudīta ielāde, kļūdu un tukšie stāvokļi, filtri un mobilā izvēlne. Pārbaudīta forma un saglabāšana pēc pārlādes. Pārlūka automatizētajās pārbaudēs laikapstākļu atbilde bija testa dati. Atsevišķi pārbaudīts arī dzīvais Open-Meteo pieprasījums 7. nedēļas lapā.

## Papildu uzdevums

Katrai lapai ir savs pārlūka cilnes nosaukums.

Mainot lapu, ritinājuma vieta vēl var palikt iepriekšējā. Tas tiek labots 7. nedēļā.
