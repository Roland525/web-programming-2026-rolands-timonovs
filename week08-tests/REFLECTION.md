# Individuālā refleksija

Aizpildiet šo daļu individuāli nodarbības beigās, **neizmantojot mākslīgā intelekta rīkus**.

Ieteicamais kopējais apjoms: **aptuveni 200-300 vārdi**.

---

## 1. Tests, kas krīt

10. sadaļas 1. izmēģinājumā jūs salauzāt `validate()`.

Kurš tests kļuva sarkans un kurš palika zaļš? Ko jums par šo kļūdu pateica `Expected` / `Received` rindas? Kāpēc tests ar tieši 3 rakstzīmēm (robeža) ir vērtīgāks nekā vēl viens tests ar 10 rakstzīmēm?

## 2. Ko testi neatrod

Kas notika bez `await`, un kāpēc `npm run lint` to neatrada? Kas notika ar tipa kļūdu testā: ko teica `npm test` un ko `npm run build`? Ko tas nozīmē, ja kāds palaiž tikai vienu no tām?

## 3. Kas padara kodu testējamu

Filtru mēs iznesām no komponentes funkcijā `filterProjects`. `daysUntil` pieņem `today` kā parametru.
