# CampusFlow — 4. nedēļa

React komponentes. Lapa sadalīta komponentēs. Main.tsx ielādē datus un nodod tos App ar props. Filtrs un mobilā izvēlne izmanto useState.

## Palaišana

```bash
npm ci
npm run dev
```

## Pārbaude

```bash
npm run build
npm run lint
```

Pārbaudīta ielāde, kļūdu un tukšie stāvokļi, filtri un mobilā izvēlne. Pārlūka automatizētajās pārbaudēs laikapstākļu atbilde bija testa dati. Atsevišķi pārbaudīts arī dzīvais Open-Meteo pieprasījums 7. nedēļas lapā.
